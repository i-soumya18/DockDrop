Backup

The backup engine

✓

Verified Seal

Every Drop ends with SHA-256 hash verification. Only when every file passes does the receipt say Sealed. The verification level used is always named explicitly — no vague “backup complete.”

size + SHA-256 on copy + re-read
⚡

Live progress

Watch your backup folder by folder. Real MB/s speed, per-folder ETAs, file counts. The display doesn’t show fake progress — if it stalls, it says so.

↻

Resume on interrupt

Pull the cable mid-backup. Plug back in. DockDrop reads the journal and resumes exactly where it stopped. No duplicates. No corruption. The final result is byte-identical.

≡

Backup Sets

Create named groups of folders — “My Phone”, “Work Docs”, “Videos”. Each Set has its own policy: deletion handling, optional encryption, battery threshold. One tap backs up all of them.

●

Smart defaults

Camera, Pictures, WhatsApp Media, Documents — pre-suggested with size estimates. Deletion policy defaults to “keep”. Battery threshold defaults to 20%. Encryption is off until you choose it.

🔒

Keeps deletions by default

When you delete a file on your phone, DockDrop moves it to _deleted/ on the SSD instead of removing it. A mass-delete guard stops Mirror mode if >20% or >500 files would be removed in one run.

Restore

Restore is first-class

↻

Hold to restore everything

Press and hold the “Restore everything” button for 1.2 seconds. That’s your only confirmation. No stacked “Are you sure?” dialogs. Friction is proportional to risk.

You’ll see a preview first: how many files, how much space needed, how conflicts are handled. Then you hold.

🗍

Browse & restore selectively

Navigate your backup as a folder tree. Search by name. Filter by photos, videos, documents, or deleted files. Restore a single file or a whole folder.

📲

New-phone restore

Install DockDrop on a new phone, plug in your SSD, and it detects your backup automatically. Maps source folders, grants permissions folder by folder, then restores.

📋

Restore receipt

After every restore, you get a receipt: files restored, conflicts kept-both, failures (if any). SHA-256 verified against your backup. Same trust, in both directions.

🔎

Test restore drill

Restore 10 random files to a temporary folder to verify your backup works — before you actually need it. The verification result tells you if hashes match.

📃

No-app restore

Unencrypted backups are plain folders on your SSD. You can restore them on any laptop using a file manager, with no DockDrop required. Format is documented.

Privacy & Trust

Trust by design

Not promises — architecture.

🔒

Zero network permissions

No INTERNET. No ACCESS_NETWORK_STATE. Enforced by CI — the build fails if either appears. Verifiable: Settings → Apps → DockDrop → Permissions.

≡

Open, versioned format

Plain folders under a documented directory tree. The manifest is versioned NDJSON with a commit protocol. No proprietary format, no encryption-by-default lock-in.

🔐

Optional encryption (AES-256)

Per-Set AES-256-GCM encryption, scrypt/Argon2id key derivation. Passphrase + recovery key required. If you lose both, the backup cannot be opened — we tell you that upfront.

📋

Atomic commit protocol

No file exists under its final name until fully written. The manifest HEAD pointer is only updated after the new generation passes checksum. A crash at any point leaves the previous generation intact.

⚠

Read-only source

DockDrop never modifies or deletes anything on your phone. Ever. Restore only writes to a destination you confirm on the preview screen. Your phone is always the source of truth.

📄

Log export

Export a plain-text log manually via the system share sheet. No remote logging, no crash-reporting SDK. If you need to file a bug, you share the log yourself.
